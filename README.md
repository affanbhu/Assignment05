TypeScript,

Vite

Features

Responsive and user-friendly design.

Answer:

i. JSX lets us write HTML-like code inside JavaScript.
ii. Props are passed from parent to child, while state is managed inside a component.
iii. useState stores and updates data. I used it to manage the stack/items.
iv. useEffect runs code when the component loads. I used it to load the JSON data.
v. The key helps React identify each item in a list.
vi. Conditional rendering means showing something based on a condition. I used it to show the empty stack message.
vii. The parent passes data using props. The child sends data back using a function passed through props.
